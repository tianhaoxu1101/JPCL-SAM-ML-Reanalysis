# JPCL-SAM-ML-Reanalysis

Reproducible analysis notebooks accompanying our Comment on machine-learning-based prediction and molecular design of self-assembled monolayers (SAMs) for perovskite solar cells.

## Notebooks

**1. `JPCL_Fig1_Validation.ipynb`**

Repeated nested cross-validation comparing point-wise and molecule-wise validation strategies.

- 20 repetitions
- 5 outer folds
- 4 inner folds
- Generates Figure 1 and Supporting Information Figure S1.

**2. `JPCL_Fig2_Ablation_Control.ipynb`**

Feature-family ablation and permutation negative-control analysis under molecule-wise validation.

- RDKit + Device (220 features)
- Device only (24 features)
- RDKit only (196 features)
- Generates Figure 2 and Supporting Information Figure S2.

## Dataset

Both notebooks use the corrected RDKit_10 dataset released by Li et al. following their Correction.

The dataset contains 99 device records representing 57 unique SAM molecules. The dataset file is not included in this repository.

## Running the Notebooks

1. Open the notebook in Google Colab.
2. Run the cells sequentially.
3. Upload the corrected dataset when prompted.
4. The analysis results, figures, and output files will be generated by the notebooks.

## Computational Environment

The notebooks are designed to run in Google Colab using Python and the required scientific computing libraries.

## Reproducibility

The notebooks provide the computational procedures used for the validation, feature-ablation, and permutation negative-control analyses reported in the manuscript and Supporting Information.
